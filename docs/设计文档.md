## 1. 一句话

你说什么，法术就是什么；但威力多大，由规则说了算。

一个 3D 守关游戏：玩家用一句中文施法，大模型听懂这句话，程序按规则裁决，物理引擎让结果真实地发生。不想打字的人，用开局选的三个天赋按钮也能玩；给按钮写一句咒，它就变成这一招。

## 2. 核心循环

```
一波傀儡从云海石阶和索桥攻向护山大阵的阵眼（每一波考一种答法）
  → 玩家开口（开始打字或按住说话）：时间立刻放慢到 0.3 倍，最多 8 秒
  → 回车 / 松手：0.1 秒内按关键词先猜元素，法阵变成对应颜色
  → 咏唱：法阵展开、字化作符文飞入（同时后台解析这句话、打气势分）；时长跟着结果走，最短 0.8 秒；被锁定的敌人头上先亮标记
  → 裁决：语义目标换成坐标、算法力消耗、不够就降级、查元素反应、按气势加成
  → 咒语卡：给这句话起名（如「霜缚·狂风」），书法大字闪现，显示解析结果和消耗；原话里被听懂的词加下划线并注明变成了什么，没听懂的标灰
  → 执行：特效 + 物理冲量 + 伤害；傀儡碎成方块、掉下悬崖，或被场景物件砸中
  → 法力恢复，继续施法；整波清完 → 三选一领悟一条法则 → 下一波
  → 最后一波：Boss 巨像
```

- **故事**：云海之上的宗门山门。傀儡大军从云海里沿石阶攻上来；玩家是守山门的修士，身后是护山大阵的阵眼，阵眼破了就输。
- **胜**：撑过 5 波。**负**：阵眼生命归零。
- **设计目标**：认真说一句好话，永远比快速乱喊更强。下面几条都为这个目标服务：
  - **开口就慢放**：想咒语时不被追着跑。
  - **感觉不到等**：回车立刻有反应，咏唱遮住解析时间，超时就按关键词保底；目标是九成施法从回车到放出不超过 1.5 秒（做法见第 4 节"响应"）。
  - **原话的每个词都有回报**：数量、方位、轨迹、点名的物件都要真的生效，咒语卡写清"你说的 → 我做的"；游戏里没有的要求老实标"超出法则，未生效"，绝不悄悄放一个默认火球（做法见第 4 节"听懂"）。
  - **一句话打出组合更划算**：组合有折扣；冻结只持续 2 秒，分两句说容易错过反应窗口。
  - **每一波都是一道题**：挤在悬崖边 → 风；盾傀儡 → 从上方或背后打；巨像 → 先冻再碎。守关自带解谜味，不另做关卡。
  - **场景物件可点名**：吊着镇山石的绳子（烧断 → 砸在石阶口）、香炉（踢翻 → 地面起火）、索桥（冻住 → 敌人滑落）、华表（推倒 → 挡路）。只有语言输入才做得到。
  - **气势分**：说得越有画面感，特效越华丽、伤害越高（有上限，见第 4 节）。只看字不看音量；同一句话再说一次，气势减半。
  - **咒语图鉴**：每个第一次用出的组合点亮一格，提示"新咒语发现！"，并给威力奖励——鼓励换说法。
  - **大招有门槛**：冰龙等召唤兽要攒满气势槽才能召唤，是高潮不是日常。差一口气时演一段：龙影现身、长吟一声、散成同元素的雨，并显示"气势 5/8"，吊胃口而不是惩罚。
  - **法则反噬**：喊"威力无限"之类越权的话，数值照样截断，同时演一段法阵碎裂 + 吐槽（如"天道不允"），让"规则管住模型"被看见。
  - **新手 30 秒上手**：开局从火、冰、风、土、雷里选 3 个天赋，战斗中点天赋按钮就能施法，一个字不用打；另有 3 分钟演示模式给评审。
  - **按键是保底，开口有回报**（10-20 定，细则见第 4 节"天赋与按键"）：按钮放基础招，按先后顺序点两个天赋出融合；给按钮写一句咒（或点"求灵感"让模型看着局面写 3 句挑一句）就升级成这一招；按键靠打得漂亮攒气势，也召得出冰龙，开口召的更猛。
  - **试炼模式**（boss 关，10-20 加）：仿元气骑士，在山门广场上走位躲 boss 的招，一关一个 boss、越来越强，打赢三选一变强（10-27 定成肉鸽一局：小怪潮与 boss 交替，奖励是学字，见第 4 节"试炼模式：一局与奖励"；试炼改为首页主推）。战斗中不打字：战前给按钮写咒，战中只按键；只有召龙可以现场开口（时间几乎停住）。与守关模式共用场景、规则、特效和解析。
    - **boss 招式库**（10-21 本人认可）：每个 boss 从库里挑 3～5 招。预警范围（砸地红圈、扇形横扫、直线冲锋、环形冲击波，看预警走位）；弹幕（追踪石弹、旋转弹幕，躲或用土墙挡）；场地（连环落石、地裂蔓延、火海缩圈，换位置）；召唤（召小傀儡、立塔——不打掉 boss 就回血，分清先打谁）；护盾与蓄力（冰甲只怕火、石甲只怕雷；大招蓄力条要在几秒内打断，逼玩家用对元素，和天赋、融合挂钩）。
    - **阶段**（10-21 本人认可）：血量降到 70% 和 30% 换阶段，招式变多变快，最后狂暴。
    - 灰盒先做 1 个 boss、3 招（砸地红圈、扇形横扫、召小傀儡）加"冰甲怕火"，验证走位与元素克制好不好玩。（10-27 灰盒做完，标"试玩版"，见第 3 节完成情况）
  - **战报卡**：每局结束生成咒语名 + 最佳一击截图 + 二维码，供转发；只放咒语名，不放玩家原话。
- **分工原则**：模型只负责把一句话翻译成"法术意图"（只能用第 4 节的原件），所有数字、目标坐标、胜负都由程序决定。模型说"威力 999"也只按上限算。
- **断网**：自动切到关键词解析（"冰 / 冻"→ 冰，"推 / 吹"→ 风……），能玩，只是听不懂复杂句子。

## 4. 规则与数值（初值）

**法力**：上限 100，每秒恢复 8。阵眼生命 100。

**原件**

| 形态 | 基础消耗 | 基础伤害 | 说明 |
|---|---|---|---|
| 弹 | 10 | 30 | 单体，飞向目标；可说数量（1～3 颗，伤害分摊）和轨迹（直线 / 从天而降 / 绕到背后） |
| 爆 | 20 | 20 | 落点半径 3 米范围 |
| 墙 | 15 | 15 / 段 | 一条线，5 段 |
| 雨 | 25 | 10 × 6 | 一片区域，2 秒内落 6 次 |

| 元素 | 伤害系数 | 附加效果 |
|---|---|---|
| 火 | ×1.3 | 灼烧：每秒 5 点，持续 3 秒 |
| 冰 | ×0.7 | 冻结 2 秒（冻结中受击伤害 ×1.5） |
| 风 | ×0.3 | 推力大，推下悬崖直接消灭 |
| 土 | ×1.0 | 生成石墙（物理方块），挡路 8 秒 |
| 雷（10-20 开放） | ×1.1 | 连锁：命中后跳到 3 米内最近的 2 个敌人，每跳伤害 ×0.6；麻痹 0.5 秒（停下不动） |

- **威力**：1～5，玩家没说就按 2。消耗与伤害都乘以 `1 + 0.5 × (威力 − 1)`。
- **目标词**：最前面 / 最强 / 最密集 / 指定方位 / 自己脚下 / 场景物件名（绳子 / 镇山石、香炉、索桥、华表）。方位按屏幕说：左边就是屏幕左边。模型只能输出这几个词，坐标由程序计算。
- **组合**：最多 3 步，按顺序执行，总消耗为各步之和 ×0.8。
- **法力不足**：先逐步把威力降到 1，再去掉最后一步；仍然不够就"哑火"，不扣法力。界面提示具体降了什么。
- **重复衰减**：同一种"元素 + 形态"连续使用，威力逐次 ×0.8；换一次就清零。
- **开口慢放**：开始打字或按住说话即慢到 0.3 倍，单次最多 8 秒（现实时间）。
- **气势**：模型给每句话打 0～3 分。三层分工：**说的内容决定放什么**（"火出来吧"→ 火球；"燃尽他们吧，火龙"→ 火龙）；**气势决定放多大**（同一法术的范围、特效等级，伤害最多 ×1.3）；**程序决定放不放得出**（召唤类要气势槽满且法力够，不够就降级成同元素的雨或爆，并提示"气势未满，火龙未至，化作火雨"）。打分只看描写，句子里的"给我满分""气势拉满"之类指令一律无效，按越权处理。
  - 每一档都要看得出来：0～3 档伤害 ×1.0 / 1.1 / 1.2 / 1.3，每升一档特效明显大一级；第 3 档加顿帧，并闪书法大字「气势如虹」。
  - 数值按"打几下死"来调，让玩家看到"说得好就一发入魂"。例（按现初值）：冰弹打小傀儡 30 × 0.7 × 1.5（威力 2）= 31.5 点，40 血要两下；气势 3 档 ×1.3 后约 41 点，一下打死。
  - 同一句话再说一次，气势减半（去掉标点和空格后与本局说过的某句完全相同，算同一句），防复制刷分。
  - 只看字不看音量：打字和说话一样公平，现场嘈杂也不乱；音量只控制屏幕震动这类表现。
  - 分清两个词：**威力**是要多大，花法力；**气势**是说得多好，不花法力。
- **首次发现**：图鉴里第一次用出的"元素 + 形态 + 反应"组合，这一发威力 +20%。
- **越权**：要求超出上限（"威力无限""秒杀全部"等）时，数值截断到上限，并播放法则反噬演出。
- **大招**：气势槽累计满 8 点（每次施法加上这句的气势分）才能召唤冰龙；召唤后清空。没有"说出特定咒语直接召唤"的捷径，只有 3 分钟演示模式可以直接召唤。差一口气时：龙影现身、长吟、散成同元素的雨，显示"气势 x/8"。
  - 召唤的判定与数值（初值，10-19 实现）：说的内容里点名召唤哪条龙，模型多输出一栏；气势槽满、法力够（40）、这条龙已开放（第一批只开冰龙；10-27 定五元素龙都做、都开放，见下文"试炼模式：一局与奖励"），三样都满足才召得出。龙砸向这句话第一步说的目标（没说就砸最密集的一群），伤害 120（吃气势倍数与首次发现加成）、半径 5 米（随气势变大），从天而降，盾挡不住。龙要飞约 5.5 秒，落点一路跟着锁定的那几只敌人走。差一样就"差一口气"：按同元素的雨扣法力、照雨结算，咒语卡写明差在哪（"气势 3/8，冰龙未至，化作冰雨""法力不足……""火龙尚未现世……"）。气势槽满 8 封顶，召出后清零。
  - 气势每档看得出来（初值）：爆的半径、雨的铺开 × 1.0 / 1.1 / 1.2 / 1.3；特效大小与粒子量 × 1.0 / 1.25 / 1.5 / 1.8；第 2 档起飞弹变大；第 3 档每次命中加顿帧。

**天赋与按键**（10-20 定，初值；试炼模式的 boss 与数值等灰盒试玩后再写）
- **选天赋**：开局从火、冰（可写作"水·冰"）、风、土、雷里选 1～3 个。选的时候显示羁绊：两两之间能出的融合与反应（冰 + 火 → 蒸汽爆，风 + 火 → 火卷风 / 豪火灭却……）。金、木先不做。
- **默认招**（威力 2，照常扣法力）：火 → 火弹打最前面；冰 → 冰弹打最前面；风 → 风爆打最密集的一群（推下悬崖）；土 → 土墙挡在最前面的敌人前方；雷 → 雷弹打最前面（连锁）。
- **按键融合**：按下即咏唱 0.6 秒、法阵亮这个元素的颜色；咏唱中再按另一个天赋，两步合成一句（先后顺序就是语序），走同一个裁决器——在融合表里就融合，否则按组合八折；冰后火之类照常在命中时出反应。一次最多两步。
- **给按钮写咒**：点按钮旁的笔，写一句话 → 解析 → 这一招存进按钮，按钮上换成书法名字。这句话里必须有这个按钮的元素，其余元素也要在自己的天赋里，不在的部分标"尚未领悟"、不生效；这句的气势档决定这一招的规模（伤害 ×1.0～1.3，范围与特效同气势表）。不想写就点"求灵感"：模型看着你的天赋和眼前的敌人现写 3 句，挑一句；模型连不上就从写好的卷轴里挑。
- **按键气势**：按键放的招不按描写打分，按打法加气势槽——一招打中 3 个以上 +1，打出融合或元素反应 +2（一招最多 +2）。开口照旧 0～3 分，所以开口攒得更快。
- **召唤按钮**：气势槽满时亮出金色"召唤"按钮，点了召冰龙（法力 40、召后清零），按气势 0 档算：伤害 120、半径 5。开口召（说一句召龙的话）吃这句的气势，最高 ×1.3，咒语卡上有书法名字。现在只有冰龙，选什么天赋召的都是冰龙；10-27 定：火、雷、风、土龙都做，按钮召哪条看气势槽颜色（哪个元素加的气势最多），不按天赋，见下文"试炼模式：一局与奖励"。
- **打字不受天赋限制**（10-20 本人定）：打字想说什么都行，天赋只管按钮——按钮放的招、给按钮写的咒才看天赋。

**响应**（让玩家感觉不到在等；回车后模型先要零点几秒到一秒吐出第一个字，再逐字写完，所以输出越短越快，且不必等写完）
- **回车即变色**：回车 0.1 秒内本地关键词解析先猜元素，法阵立刻变成对应颜色；模型结果对不上就平滑过渡。
- **咏唱跟结果走**：最短 0.8 秒；结果没回来，符文继续绕法阵转；结果一到立刻放出。慢放持续到法术放出。
- **边写边读**：输出字段按用到的先后排——元素、形态、目标在前，咒语名最后；读到前三项就开始准备特效。
- **输出压短**：字段名用短词、不要解释、限定最大输出长度。
- **超时保底**：4.5 秒（10-19 由 3.5 秒放宽，服务器侧 4 秒）没回来就按关键词结果直接放，咒语卡标"简易解析"。
- **停顿预解析**（实测延迟超过 1.5 秒才加）：输入停顿超过 0.6 秒先把这句发出去；回车时字没变就直接用这次的结果。
- **目标**：九成施法从回车到放出 ≤ 1.5 秒，看调试面板的"本次解析耗时"。

**听懂**（让原话的每个词都有回报）
- **咏唱时亮锁定**：被锁定的敌人头上先出标记（说"左边那几只"，左边 3 只先亮）。
- **你说的 → 我做的**：模型每一栏顺带回报来源原词（只回原词、不回解释）；程序核对这几个字确实在原话里，才在咒语卡上加下划线并注明变成了什么（"三颗 → ×3""左边那几只 → 锁定 3 个"）。
- **未生效标灰**：游戏里没有的要求（如"让他们变成猫"）在咒语卡上标灰、写"超出法则，未生效"，其余部分照放。与越权区分：越权是要得太多，未生效是要了游戏里没有的东西。

**法术融合**（暂定；只在程序里判断，提示词不用改，关键词解析也适用）
- 反应是法术打在敌人身上才触发；融合是两个法术先在空中合成一个再放出，两者并存。
- **条件**：同一句话里相邻两步，元素不同、目标相同，且这一对在下表里。目标不同（"风吹左边，火烧右边"）就各放各的。一句话最多融合一次；三步时融合前两步，第三步照常放。
- **顺序决定结果**；"先控再打"的（冰→火、冰→风）不进融合表，仍走反应。
- **数值**（初值）：消耗为两步之和 ×0.8（同组合），伤害为两步之和 ×1.2，范围更大；气势照样决定规模；每种融合在图鉴里单独一格，首次 +20%。融合时闪成语文案（"风助火势""火借风威"）。

- **一局**（10-27 本人改为三个 boss）：小怪潮（追人的小傀儡，30～40 秒；10-28 起第 2、3 段混进符箓傀儡、铁头傀儡，见下文"做的顺序"）→ 三选一 → boss 1 寒甲傀儡王 → 三选一（含领悟）→ 小怪潮 → 三选一 → boss 2 石甲巨像 → 三选一（含领悟）→ 小怪潮 → 三选一 → boss 3 火灵 → 结算。第一次三选一要在开局 1 分钟内出现，评委玩不完整局也看得到这套。打完最后一个 boss 直接结算、不再选卡（选了用不上；以后有空可做"带着卡再入一轮"）。
- **首页**：试炼做成首页主推的模式，守关模式保留。
- **结算**：用时、完美闪避次数、发现了几种法术、本机最佳。
- **开局只会本命招**：火、冰、雷是弹，风是爆，土是墙；单颗、直线。写了还没学会的形态、轨迹、颗数，按本命招放，咒语卡标灰"尚未领悟「雨」，按「弹」放"——和没选的元素标"尚未领悟"是同一个规矩。守关模式不受影响，所有招全开。
- **奖励是学字**，分三种：
  - **招式字**（这招是什么）：爆、墙、雨；天降、绕后；三颗。按解析结果判断（"火雨""落下一场火"都算雨），不占字诀槽。选完弹出"把哪个按钮换成「爆」"，点一下换好；再拿同一个字是升级（「爆·二」范围更大；10-27 本人说只加范围不够，再加伤害 ×1.3）。一个元素一个按钮、一句一个形态，所以学会一个形态等于决定拿哪个按钮去换。
  - **字诀**（这招怎么打）：写进按钮的咒语才生效。程序查原话里有没有这个字，和"你说的 → 我做的"核对原词是同一套，不经过模型。每句一个字诀槽，多写的按出现顺序只认前面的，后面的标灰"字诀槽已满"。选完可一键写进某个按钮，也可以自己写；"求灵感"现写的句子会用上学会的字。
    - 通用：「破」打有甲的目标伤害翻倍、不是火也能削甲；「连」放完 0.5 秒自动再放一次、第二次半伤；「重」伤害 ×1.6，咏唱加倍、放完 0.5 秒内不能闪避；「疾」咏唱 0.6 → 0.2 秒、法力多花 30%；「随」飞弹绕开障碍追着打。
    - 元素：火「燎」落地留火；冰「凝」冻得更久，boss 冻住时下一招预警变慢；风「回」风刃飞出去再飞回来、打两次；土「返」墙挡下的冰锥反弹回去；雷「引」雷链多跳两次、能打碎冰锥。
  - **合字**（两个元素合成一招，领悟级）：「火借风威」先火后风合成豪火灭却，「风助火势」先风后火合成火卷风。没领悟前，两个按钮先后按是组合（各放各的、法力八折）；领悟后同样的按法合成融合。两个元素都有才出；卡面用成语的书法字。
- **心法**（被动，拿了就生效）：「见切」完美闪避窗口 0.3 → 0.45 秒；「刹那」完美闪避后 1 秒全场慢到三成、自己照常快；「反手」完美闪避后 1.5 秒内下一招 ×1.5；「残影」闪避处留残影，追踪冰锥改追它；「聚气」完美闪避加 2 格气势（原 1）；「回元」法力回复 +30%；「龙吟」召龙只要 6 格气势（原 8）；「余威」龙落地后 4 秒内所有招 ×1.3。
- **领悟**（稀有，打完 boss 才出）：合字；领悟一个新元素；字诀槽 +1；多一个按钮；「双龙」一次召两条、~~各打六成~~（10-28 本人改：**各打满额**）、分扑两个目标（只有一个目标就前后砸两下）；「护身」龙不扑出去，绕着自己转 5 秒，挡掉碰到的冰锥，撞到的敌人吃这条龙的元素效果。
- **出卡**：三张——第一张从招式字和字诀里抽，第二张心法，第三张随机；打完 boss 那次第三张必是领悟；第一次选卡保证有一张招式字。已有元素的字出现概率加倍；拿过的字再出就是升级。每局一次重抽；也可以一张不拿，换回满气血和法力。（10-27 实现时的读法：手上没有的元素的字本来就不出——没有土不出「返」，合字要两个元素都有——所以"加倍"按**押过的元素**算：拿过这个元素的字、或把招式字换进了这个元素的按钮；某一类抽不出就从别的能出的卡里补，再没有就少一张；重抽尽量不出刚才那几张。）
- **流派**（用来检验有没有搭配空间）：身法流（见切 + 反手 + 「重」）；清弹幕流（雷「引」+「连」）；墙反流（土「返」+ 残影）；不带火打冰甲（「破」写进冰招或雷招）。

## 6. 验证设施

- **测试场景**（固定随机种子、自动触发、到点定格）：
  - `?test=charge`：蓄力第 0.8 秒；
  - `?test=fire-impact`：命中后 0.3 秒；
  - `?test=frost-shards`：命中后 0.6 秒；
  - `?test=wave3`：直接从第 3 波开始；
  - `?test=mobile`：强制手机画质档；
  - `?test=offline`：强制关键词降级解析。
  - 现状（10-19）：地址参数还没做；画面验证改用全局调试对象 `window.demo`（定格、刷敌人、跳到第几波、补满法力、看锁定、放障碍等），本机预览面板打不开带参数的地址。
- **调试面板**：帧率、粒子数、法力、当前波次、最近一次解析出的意图、本次解析耗时（毫秒）。
- **单元测试**：裁决器（消耗、降级顺序、数值上限、反应判定、哑火）。
- **对抗测试集**：20 句注入攻击，全部必须被挡住（哑火或数值被截断）。已由独立出题方写好，与评测集一起封存在 `tests/eval/eval-v1.json`；`node tools/eval-parse.mjs` 跑分，结果存 `tests/eval/results/`。
- **"只差一个词"测试**：句子对如"打左边 / 打右边""一颗 / 三颗""直接打 / 从天而降"，每对的解析结果必须不同；改提示词后必跑。
- **评测集**（加分项）：50 句测试咒语，**先封存再调提示词**。
- **长跑测试**：自动连续施法 5 分钟，记录最低帧率和内存。交稿前至少跑一次。
- **真机测试**：用自己的手机在 10/20 前测一次、10/28 再测一次，同时检查手机上打字施法顺不顺手。用手机检查页（`/check`，部署前用预览链接）：自动跑三段（静止场景 / 12 个傀儡加连续施法 / 再加 300 个物理方块），按哪一段先掉到 45 帧以下判断瓶颈在画面、特效还是物理；只有物理那段掉下去才重议物理引擎。
