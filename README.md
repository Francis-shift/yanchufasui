# 言出法随

说一句中文就能施法的 3D 守关游戏。没有技能按钮：打字（之后也能说话）说出咒语，大模型听懂这句话，程序按规则裁决，物理引擎让结果真实地发生。

> 傀儡大军从云海里沿石阶和索桥攻上山门。你是守山门的修士，身后是护山大阵的阵眼，阵眼破了就输。

## 一句话架构：模型管语义，程序管规则

```
玩家一句话
  → 回车 0.1 秒内：关键词先猜元素，法阵变色（不等网络）
  → 咏唱（最短 0.8 秒，时间慢到 0.3 倍）同时请服务器上的模型解析
       模型只输出固定格式的"法术意图"：元素、形态、目标、威力、颗数、轨迹、来源原词、气势、名字
       3.5 秒没回来 / 断网 / 额度用完 → 改用关键词解析，照样能玩
  → 清洗（game/rules/intent.js）：枚举不在表里就丢、数值夹到上限、来源词必须真在原话里
  → 裁决（game/rules/arbiter.js，纯函数）：消耗、组合八折、法力不够就降级、伤害、气势、首次发现、打谁
  → 咒语卡：书法大字写名字；原话里被听懂的词加下划线并注明变成了什么，没听懂的标灰
  → 执行：飞弹 / 爆炸 / 冻结 / 灼烧 / 风推下悬崖，命中结算再走一遍规则（反应、盾牌减伤）
```

模型说"威力 999"也只按上限算；会影响胜负的数字只在 `game/rules/` 里算，并有单元测试。

## 目录

| 位置 | 内容 |
|---|---|
| `game/rules/` | 规则层：数值表、意图清洗、关键词解析、裁决器（纯函数） |
| `game/world/` | 场景：天空、云海、远山；山门广场、石阶、索桥、阵眼（方块版） |
| `game/actors/` | 傀儡：走路、冻结、灼烧、被风推走、坠入云海、碎裂 |
| `game/fx/` | 特效：粒子、法阵、飞弹、爆炸、冰棱、法则反噬 |
| `game/ui/` | 界面：输入框、法力与阵眼、咒语卡、浮字、开始与结算 |
| `game/main.js` | 入口：把上面接起来，施法流程与主循环 |
| `app/` | 网站（Next.js）：游戏页 + `api/parse` 解析接口 |
| `server/` | 解析接口用的提示词、防刷计数 |
| `tests/` | 单元测试（`npm test`） |
| `tools/build_preview.py` | 把游戏打成一个离线单文件页面，用于验画面 |
| `docs/` | 设计文档、试玩记录 |

## 本地运行

需要 Node.js 20.9 以上。

```bash
npm install
cp .env.example .env.local   # 填入火山方舟的 API Key 与模型名；不填也能玩（只走关键词解析）
npm run dev
```

打开 http://localhost:3000 。按 <kbd>`</kbd> 打开调试面板（帧率、粒子数、上一句的解析来源与耗时）。

```bash
npm test                       # 规则层与防刷的单元测试
npm run build                  # 生产构建
python tools/build_preview.py  # 生成 preview/index.html（离线单文件，只走关键词解析）
```

## 部署

部署在 EdgeOne Pages（加速区域选"全球可用区（不含中国大陆）"，免备案）+ 自己的域名，同一仓库接 Vercel 作后备。环境变量与 `.env.example` 同名；密钥只配在平台上，不进仓库。
